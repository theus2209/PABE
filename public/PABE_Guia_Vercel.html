O que é o Vercel?
Plataforma de hospedagem gratuita para projetos React/Vite com deploy automático via GitHub
Por que usar?
Link HTTPS permanente, deploy automático a cada atualização e zero configuração de servidor
Banco de dados
O PABE no Vercel usa o mesmo backend do app mobile — dados totalmente sincronizados
Custo
Plano Hobby do Vercel é 100% gratuito — sem necessidade de cartão de crédito
Este guia cobre todos os passos necessários para publicar o PABE no Vercel: desde a criação da conta até a configuração das variáveis de ambiente e obtenção do link de acesso. Ao final, você terá um link público e permanente que pode ser acessado de qualquer dispositivo com internet.
1
Criar conta no Vercel
Acesse vercel.com e faça login com sua conta GitHub

Acesse vercel.com no seu navegador. Caso não tenha conta, clique em "Sign Up" e selecione "Continue with GitHub". Isso vincula sua conta GitHub ao Vercel automaticamente, sem precisar inserir senhas separadas.

Se já tem conta, clique em "Log In" → "Continue with GitHub".

Ações necessárias
  • Acesse https://vercel.com no navegador
  • Clique em "Sign Up" (nova conta) ou "Log In" (já tem conta)
  • Selecione "Continue with GitHub"
  • Autorize o Vercel a acessar sua conta GitHub quando solicitado

2
Criar novo projeto — importar do GitHub
Na tela inicial do Vercel, clique em "Add New Project"

Após fazer login, você será direcionado ao Dashboard do Vercel. Clique no botão "Add New…" no canto superior direito e selecione "Project". Na seção "Import Git Repository", localize o repositório PABE.

Ações necessárias
  • No Dashboard, clique em "Add New…" → "Project"
  • Na seção "Import Git Repository", localize o repositório PABE
  • Clique no botão "Import" ao lado do repositório PABE

3
Verificar configuração do projeto
Framework detectado automaticamente como Vite

Após clicar em "Import", o Vercel detecta automaticamente que é um projeto Vite. As configurações de Build Command e Output Directory são preenchidas automaticamente. O nome do projeto pode ser alterado — ele será parte da URL final.

O que verificar
  • Project Name: Pode manter "PABE" ou alterar (define a URL final)
  • Framework Preset: Deve estar em "Vite" — detectado automaticamente
  • Build Command: vite build — não alterar
  • Output Directory: dist — não alterar
  • ⚠ NÃO clique em Deploy ainda — primeiro configure as variáveis (Passo 4)

4
Adicionar Variáveis de Ambiente
⚡ Etapa crítica — o sistema não funcionará sem este passo

Na tela de configuração, expanda a seção "Environment Variables" e adicione 2 variáveis obrigatórias que conectam o PABE ao banco de dados. São os mesmos valores usados pelo app mobile — garantindo sincronização total dos dados.

Como adicionar
  • Expanda a seção "Environment Variables"
  • Clique em "Add" e insira a primeira variável: nome + valor
  • Clique em "Add" novamente para a segunda variável
  • Certifique-se de que estão marcadas como "All Environments"

5
Clicar em "Deploy" e aguardar
O Vercel compilará e publicará o projeto automaticamente (1–3 min)

Com as variáveis de ambiente configuradas, clique no botão "Deploy". O Vercel irá: baixar o código do GitHub → instalar dependências → compilar o projeto → publicar online. Acompanhe o progresso em tempo real no log de build.

O que acontece
  • Clique no botão "Deploy" (preto, parte inferior da página)
  • Aguarde a conclusão — não feche a aba durante o processo
  • O log mostrará cada etapa: clone → install → build → deploy
  • Quando aparecer "Build Completed", o deploy foi concluído

6
Deploy concluído — acessar o link
O PABE está online — acesse e compartilhe com a guarnição

Após o deploy concluído, o Vercel exibirá uma tela de sucesso com o link permanente do projeto. O link terá o formato pabe-theus2209.vercel.app (ou o nome escolhido no Passo 3). Com HTTPS ativo e funcionando em qualquer navegador ou dispositivo.

Próximos passos
  • Clique em "Visit" ou no link exibido para abrir o PABE
  • Teste o login com suas credenciais para confirmar que o backend está conectado
  • Copie o link e compartilhe com os demais militares da unidade
  • Salve o link nos favoritos ou crie um atalho na tela inicial do celular

7
Configurar domínio personalizado (opcional)
Substitua o link padrão Vercel por um domínio próprio

Se desejar usar um domínio personalizado (ex: pabe.bombeiros.mg.gov.br), acesse no Vercel: projeto PABE → Settings → Domains. O Vercel fornecerá um registro DNS para configurar no provedor do domínio.

Para uso interno da unidade, o link padrão .vercel.app é suficiente e não requer configuração adicional.

Como configurar
  • Acesse o projeto PABE no Dashboard do Vercel
  • Clique em "Settings" → "Domains"
  • Insira o domínio desejado e clique em "Add Domain"
  • Configure o registro DNS fornecido no seu provedor de domínio
  • Aguarde a propagação (pode levar até 24h)
